# Голосовые модели реального времени для греческого и английского

*Состояние на 28.09.2026. Данные из официальной документации и независимых замеров (Artificial Analysis). Пометка «не подтверждено» означает, что официального источника не нашли.*

## Коротко

- **Нативно говорят по-гречески и позволяют перебивать** только две семьи моделей:
  - **OpenAI Realtime** (`gpt-realtime-2.1` / `-mini`, также доступна через Azure Voice Live);
  - **Google Gemini Live** (`gemini-3.8-live`).
- **Самый естественный греческий голос** сейчас, скорее всего, у каскада: распознавание речи → LLM → синтез речи. Лучший готовый вариант такого каскада — **ElevenLabs Agents**. Там встроены перебивание и определение конца реплики, а греческий официально поддерживается в синтезе Flash v2.5.
- **Для английского** выбор шире: к перечисленным добавляются Amazon Nova 2 Sonic, Hume EVI, xAI Grok Voice и новый OpenAI GPT‑Live‑1.
- **Ни один поставщик не публикует метрики качества именно для греческого.** Нужна слепая оценка носителями языка на прототипах.

## Каскад: распознавание → LLM → синтез (больше контроля над греческим голосом)

| Компонент | Греческий | Задержка | Примечание |
|---|---|---|---|
| **ElevenLabs Agents** (платформа целиком) | Да (Flash v2.5, 32 языка) | Синтез ~75 мс | Встроенные перебивание и определение конца реплики. $0.08/мин + LLM. Новая v3 Conversational (70+ языков) выразительнее; поддержка греческого в ней выведена из общего списка v3 |
| Cartesia Sonic 3.6 (синтез) | Да (`el`) | ~90 мс по заявлению, 170–190 мс по замерам | Хорош для своего каскада |
| Azure Neural TTS (синтез) | Да: `el-GR-AthinaNeural`, `el-GR-NestorasNeural` | < 300 мс | Голоса DragonHD для греческого пока только в preview |
| Google Chirp 3 HD / Gemini TTS (синтез) | Да (Gemini TTS: el-GR в preview) | Нет данных | Для el-GR нет управления паузами и произношением |
| Deepgram Nova-3 (распознавание) | Да (`el`, с 12.2025) | Стриминг | Aura-2 (синтез) и Flux (распознавание с определением конца реплики) греческий **не** поддерживают |
| ElevenLabs Scribe v2 Realtime (распознавание) | Вероятно (90+ языков) | ~150 мс | |

Для сборки каскада подходят **LiveKit Agents** и **Pipecat**. Оба умеют перебивание, но их модели определения конца реплики греческий **не** поддерживают. Для греческого конец реплики придётся определять по паузе (VAD или сигнал от распознавания), это добавляет ~300–500 мс.

## Open-source

- Открытых full-duplex моделей с греческим **нет**: Moshi, PersonaPlex, Qwen3-Omni, MiniCPM-o и Step-Audio говорят только на EN/ZH и нескольких европейских языках.
- Для своей инфраструктуры реален только каскад:
  - распознавание: Whisper-turbo (MIT) или Parakeet v3 (WER 20.7% на греческом FLEURS);
  - синтез: **Chatterbox Multilingual** (MIT, греческий есть);
  - LLM: любая.
- XTTS v2 не подходит: нет греческого и некоммерческая лицензия. MMS-TTS и Piper по качеству для продукта не годятся.

## Рекомендация

1. **Быстрый вариант, «как OpenAI Realtime»:** сравнить `gpt-realtime-2.1` и `gemini-3.8-live` на греческом. Обе модели нативно speech-to-speech, перебивание работает из коробки, прототип займёт 1–2 дня.
2. **Если греческий голос звучит неестественно** (акцент, ударения, числа): **ElevenLabs Agents** с Flash v2.5 или v3 Conversational. Задержка сопоставимая, голос обычно заметно естественнее.
3. **Отдельно проследить за `gpt-live-1`**: по заявлению OpenAI, это лучший тайминг перебиваний. Как только появится список языков, проверить греческий.

## Что проверить на прототипах

- Задержку от конца фразы пользователя до начала ответа, p50 и p95.
- Естественность греческой речи: слепая оценка 3–5 носителями по шкале 1–5. Отдельно проверить акцент, ударения, числа и даты, имена.
- Перебивание: реакцию на «ναι / ага» (не должна обрывать ответ) и на реальное перебивание (должна обрывать за < 300 мс). Проверить эхо: бот не должен перебивать сам себя.
- Смешанную речь греческий + английский.
- Цену минуты при диалоге 5–10 минут. У Realtime цена растёт с длиной контекста.
