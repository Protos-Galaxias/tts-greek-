# Прототип: голосовой агент на OpenAI Realtime (греческий/английский) — дизайн

Дата: 2026-09-28

## Цель

Демо-страница, на которой можно голосом разговаривать с OpenAI Realtime по-гречески и по-английски, перебивать модель и **измерять** задержку ответа и скорость реакции на перебивание. Результаты (JSON) используются для сравнения моделей/голосов/настроек VAD и для отчёта заказчику.

## Подход

Браузер соединяется с OpenAI напрямую по WebRTC. Локальный Node-сервер только выпускает ephemeral token (API-ключ не попадает в браузер) и отдаёт статику. Аудио через наш сервер не идёт.

## Структура

```
tts-greek/
  server.js          # Node 20+, встроенный http, без зависимостей
  public/
    index.html       # UI
    app.js           # WebRTC, обработка событий, UI
    metrics.js       # чистые функции: перцентили, расчёт задержек (тестируется)
  test/
    metrics.test.js  # node --test
  .env.example       # OPENAI_API_KEY=
  .gitignore         # .env
  README.md          # запуск + ручной чек-лист
```

## Сервер (`server.js`)

- Читает `OPENAI_API_KEY` из окружения или `.env` (простой парсер, без dotenv).
- `GET /` и статика из `public/`.
- `POST /token` с телом `{ model, voice }` → `POST https://api.openai.com/v1/realtime/client_secrets` с `{ session: { type: "realtime", model, audio: { output: { voice } } } }` → возвращает клиенту `{ value }` (ek_…). Ошибки OpenAI пробрасываются с кодом и текстом.
- Порт: `PORT` или 3000.

## Клиент (`public/app.js`)

**Подключение:**
1. `POST /token` → ephemeral key.
2. `getUserMedia({ audio: { echoCancellation: true, noiseSuppression: true, autoGainControl: true } })`.
3. `RTCPeerConnection`: микрофонный трек, data channel `oai-events`, `ontrack` → `<audio autoplay>`.
4. SDP offer → `POST https://api.openai.com/v1/realtime/calls` (Bearer ek, `Content-Type: application/sdp`) → answer.
5. После открытия data channel — `session.update`: `instructions`, `audio.input.turn_detection` (выбранный режим), `audio.input.transcription` (`gpt-4o-transcribe`) для отображения реплик пользователя.

**Настройки (до подключения):**
- модель: select `gpt-realtime-2.1`, `gpt-realtime-2.1-mini` + текстовое поле для произвольного id;
- голос: select (marin, cedar, alloy, ash, ballad, coral, echo, sage, shimmer, verse) + произвольный;
- VAD: `semantic_vad` (eagerness: auto/low/medium/high) или `server_vad` (silence_duration_ms, по умолчанию 500);
- промпт по умолчанию: «Ты голосовой ассистент. Отвечай на языке собеседника — греческом или английском. Говори коротко и разговорно, 1–3 предложения.»

**UI:** кнопки Подключиться/Отключиться, Mute, Экспорт JSON; два индикатора уровня (микрофон, бот); транскрипт (пользователь/бот, прерванные ответы помечены ✂️); таблица метрик по репликам и сводка.

## Метрики

Все времена — `performance.now()` на клиенте.

- **Уровни звука:** два `AnalyserNode` (микрофон и удалённый поток), RMS каждые ~20 мс через `requestAnimationFrame`/таймер. Порог речи — константа (по умолчанию RMS > 0.02), настраиваемая в коде.
- **Событийная задержка:** `t(output_audio_buffer.started) − t(input_audio_buffer.speech_stopped)` для того же хода.
- **Акустическая задержка:** `t(первый кадр бота выше порога) − t(последний кадр микрофона выше порога перед speech_stopped)`. Это ощущаемая задержка «замолчал → услышал ответ».
- **Перебивание:** если `input_audio_buffer.speech_started` приходит, когда бот звучит, — фиксируем `t(speech_started)` и `t(бот ниже порога ≥ 200 мс)`; метрика — `t(тишина бота) − t(начало речи пользователя по микрофону)`. Ответ помечается как прерванный (также по `output_audio_buffer.cleared` / статусу `cancelled` в `response.done`).
- **Сводка:** p50/p95 для обеих задержек и для перебиваний, число ходов и перебиваний.
- **Экспорт JSON:** настройки, метрики по ходам, сводка, транскрипт, сырой лог событий (без аудио-дельт) с таймстемпами.

## Обработка ошибок

Показывается баннер с понятным текстом, страница не ломается:
- нет ключа / 401 от OpenAI (текст ошибки из `/token`);
- отказ в доступе к микрофону;
- ошибка SDP-обмена;
- событие `error` из data channel (показать `error.message`, продолжить сессию);
- обрыв соединения (`connectionstatechange` → failed/disconnected) — кнопка снова «Подключиться».

## Тестирование

- `node --test`: юнит-тесты `metrics.js` (перцентили на известных наборах, расчёт задержек по синтетическому таймлайну событий и уровней).
- Ручной чек-лист (README): греческая фраза → ответ по-гречески; английская → по-английски; перебить длинный ответ; «ναι»/«ага» во время ответа; проверка памяти через 3 реплики; числа/даты по-гречески; экспорт JSON открывается и содержит метрики.

## Риски

- Названия моделей/голосов и форма `session.update` в GA API могли измениться — при реализации сверить с актуальной документацией OpenAI; произвольные поля модели/голоса оставлены как страховка.
- Эхоподавление браузера на ноутбучных динамиках может давать ложные перебивания — для замеров рекомендуются наушники; зафиксировать в README.
